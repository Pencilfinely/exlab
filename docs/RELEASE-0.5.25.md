# ExLab 0.5.25 — 修复主控端口复用与连接异常诊断

- Windows 主控使用独占监听，禁止不同数据目录的主控同时绑定同一个端口，避免健康检查、节点心跳和凭证校验连到错误实例。
- 健康检查返回工作空间身份；认证失败、身份不匹配、请求过载、超时与无效回复分别提供原因。发现端口属于另一份工作空间时不再尝试启动第二个后台。
- 桌面状态将 `unresponsive` 显示为“主控连接异常”，同时保留具体错误与数据目录。切换数据目录前要求当前主控已停用，避免遗留运行中的旧实例。
- 启动日志记录实际打开的桌面设置文件物理路径，便于识别 Windows AppData 重定向副本与普通启动配置之间的差异。安装与恢复时应在普通用户进程中核对真实配置，不能仅在重定向环境中读回验证。

包含 0.5.24 的配置备份、登录自启/更新设置入口及 Worker SQLite 锁恢复修复。Monitor APK 仍为 0.5.22。已有实验数据、节点凭证和 AI 配置沿用原工作空间；无需重新配对。
