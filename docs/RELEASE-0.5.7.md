# ExLab 0.5.7

算法项目库改为可搜索、按部署状态筛选和排序的项目列表。列表限高滚动，每页可选 10、20、50 或 100 条，支持跳页；直接显示导入日期时间、项目版本及节点准备情况。

点击项目打开操作窗口，在 **部署到算力端 → 创建实验 → 项目详情** 中完成操作。部署支持搜索节点、一键选择在线待部署节点、查看安装失败原因并重试。离线节点可先排队，安装进度自动更新，准备完成后可直接创建实验。

创建实验使用参数、资源预算、算力分配与标签表单。切换实验配置或关闭重开窗口，会保留当前页面中的各份输入，包括尚未修正的无效内容；可以恢复配置默认值。提交前可预览分配，也可直接转为实验矩阵。提交响应丢失时，重复提交相同内容会复用同一次请求标识。

导入文件夹分为 **文件夹、入口与参数、数据与环境、指标采集、检查与发布** 五步。常用操作集中在当前步骤，高级配置按需展开；保存草稿保持所在步骤，无效输入会定位到对应页面。发布前显示配置摘要和文件清单，加入项目库后直接打开节点部署窗口。

验证覆盖项目分页和筛选、项目版本匹配、输入保留、后台刷新时的焦点稳定、节点选择与重复分发防护、提交重试、算力预览、矩阵转换、部署完成后的配置展示、键盘操作和导入步骤校验，并通过真实项目包的浏览器流程验收。Monitor APK 保持 0.5.2。
