# ExLab 0.5.11

修复任务长时间显示 running 时缺少可核验运行证据的问题。Center 现在分别展示节点心跳、日志是否读取成功、日志最后变化时间、容器暂停或重启状态；不再把节点在线或容器存活解释成训练持续推进。

Windows Worker 为所属任务回传有大小和频率限制的只读诊断。日志停滞或读取失败时采集容器进程、等待位置、CPU/内存统计和分配 GPU 的活动信息。诊断使用精确容器身份和固定命令，输出不含进程参数或环境变量；查询失败明确显示，不覆盖最后成功日志。

本版沿用 0.5.10 的管理进程交接，升级时保留实验容器、任务身份、现有训练及结果。诊断本身不会停止、重试或重训任务，也不把日志停滞自动判定为训练失败。旧 Worker 仍可连接，新 Center 明确显示其尚未提供运行诊断。

本次发布 Windows Center 和 Windows Worker 安装包；不发布 Ubuntu Worker 包，Ubuntu 节点的更新选择不受此版本影响。自动更新仍仅对已经启用该选项的客户端生效。

验证：Python 全套 545 项已通过（538 通过、7 项跳过），另补充空诊断兼容和 GPU 查询隔离/失败用例；运行诊断 UI 的 10 项断言通过。所有验证均为本机测试，不新增科学训练或 test。
