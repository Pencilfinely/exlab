# ExLab 0.5.30

修复 Windows Worker 迁移被其他 Docker 容器一概拦截的问题，并精简客户端界面。

- 不相关的 Docker Desktop 容器可以继续运行。只对迁移涉及的 WSL 挂载、Worker 仓库卷及无法核验的挂载进行拦截，列明容器名称和原因；关闭 Ubuntu 前再次检查。
- Worker 分为“概览 / 设置 / 日志”。概览保留启用、停用和暂停接单；连接、显卡、自启和更新集中到设置，详细状态与版本保留在日志中。
- 从概览直接设置开机启动。迁移窗口默认收起环境与目录选项，仅在未完成迁移时显示恢复按钮；管理员授权保留所选环境和目录，密码不会传入命令行。
- 精简显卡、暂停、自启和迁移提示，保留具体错误及必要的停止行为说明。

更新后打开 **Worker → 概览 → 设置开机启动**。如果仍有阻塞，请按新版提示查看具体容器和挂载原因，无需先停止全部 Docker 工作。

已通过自动化回归与 Windows 界面检查。未登录启动仍需部署后在目标服务器完成重启验收。
