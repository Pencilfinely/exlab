# ExLab 0.5.28 — Windows 无人值守启动

Worker 增加“无人值守启动…”设置入口。对已配置独立 Docker Engine、NVIDIA Container Toolkit 和原节点的 WSL2 环境，可登记使用 Windows 账户批处理登录的开机任务；无需先打开桌面窗口。

- 启用前检查发行版内的 Docker 进程、引擎身份、GPU 和节点配置；Docker Desktop 环境会被拒绝。
- 密码只交给 Windows Task Scheduler，不写入配置或命令行。任务延迟启动、失败重试、无运行时限，并通过跨会话文件锁防止重复后台。
- 登录后的客户端控制同一后台，窗口退出不结束无人值守任务；本机停用和主控释放优先于自动启动。
- 资源释放只作用于所选专用 Ubuntu；存在其他工作或无法核查时保留运行环境。Windows 控制进程保持在线等待主控恢复。
- 更新前交接管理进程，稳定启动脚本定位已安装版本；关闭开机启动保留当前运行和节点数据。
- 配置原子写入补充 Windows 错误 1175 的有限重试，避免目标文件临时无法替换时丢掉此次设置保存。

新模式需要先完成独立环境准备及原节点数据迁移。本版不自动搬迁 Docker Desktop 数据，也不自动卸载 Desktop。登记成功不等于冷启动验收成功；必须实际重启、保持未登录，从另一台设备确认原节点并运行 GPU 任务。

见 [配置、迁移前提及验收](UNATTENDED-WORKER.zh-CN.md)。
