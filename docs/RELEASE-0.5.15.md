# ExLab 0.5.15 — 更直接的节点暂停与恢复

节点卡片现在提供「暂停节点…」和独立的「恢复接单」。暂停只需两步：选择怎样暂停，再选择暂停多久。

| 选择 | 当前实验 | 恢复方式 |
|---|---|---|
| 只暂停接单 | 继续运行并占用资源 | 允许分配新任务 |
| 停止当前实验 | 保存并停止，保留本机任务与环境 | 先恢复接单，再在实验详情中手动续训 |
| 释放训练资源 | 保存并停止，清理实验容器，可续训任务交接 | 按原有交接与调度机制接手 |

- 默认由自己手动恢复，也可选择 1 / 2 / 4 小时后或指定时间。提交按钮直接写明会执行的操作，不再要求填写节点类型、可靠度、维护时间等整套策略。
- 修复旧接单开关与可用策略各自暂停、恢复一处仍被另一处拦住的问题。快捷操作在同一事务中更新策略并解除旧接单开关，校验策略版本与原节点状态，丢失响应后可以重试。
- 本机手动暂停、电源条件与维护时间分别提示；如果管理端已经没有手动暂停，恢复窗口明确展示剩余条件，不再提供无效的恢复操作。
- 电源条件、维护计划、可靠度等移到「节点长期设置」，修改时保留当前暂停方式与到期时间。Windows Worker 使用三种明确选项、时间预设与独立的本机恢复按钮。
- Center 与 Android/HarmonyOS Monitor 共用新版页面；只读与离线移动端仍不能提交控制操作。旧 Worker 保留基础暂停接单，停止实验与资源核验需要升级 Worker。

停止与释放仍以 Worker 的执行回执为准，策略接收不代表执行完成。释放训练资源保留控制代理及共享 Docker/WSL；完全退出使用 Windows Worker 主窗口的「停用并释放 Docker / WSL」。

提供 Windows Center/Worker 安装器与 ZIP、Ubuntu Worker ZIP、Android Monitor 0.5.15 APK（versionCode 6，沿用原调试签名），附 SHA-256 清单及构建信息。旧仓库更新渠道提供逐字节相同的 Windows 安装器。HarmonyOS 工程版本同步更新，本次不提供原生 HAP，可使用 `/mobile/` 网页。

发布检查包括 Python 回归、JavaScript、Windows 原生编译与暂停操作、Android 单元测试/构建/Lint、桌面及 390 像素手机页面预览、发行包与升级下载校验。交互验证使用隔离模拟节点与本机测试，不操作真实训练、调用付费模型或承诺未配置续训的实验可恢复。
