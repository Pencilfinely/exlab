# 0.6.0：资源与生命周期改造

目标：减少迁移峰值和日常冗余，降低后台开销，使清理、环境与资源状态可见。保持节点身份、结果、权重、科研参数和可恢复实验不变。

## 交付范围

- 存储：区分实验档案、源代码、运行工作副本、镜像与临时文件；扫描明细；按所有权和引用清理；记录实际磁盘变化。
- 实验生命周期：完整保存结果、权重与续训数据；按版本归档代码和环境身份；回收已结束实验的可重建副本和容器。
- 迁移：按阶段计算峰值；分批镜像传输；导入并验证后及时释放中间文件；新环境交接后清理本次旧副本，失败或中断可恢复。
- 资源：减少历史实验重复解析、重复硬件探测、后台页面轮询和无效状态写入；运行前仍使用新鲜资源数据，不改变训练参数。
- 交互：统一存储与环境入口，短状态配可展开详情；操作异步执行、可观察、不假报已释放；保留错误定位信息。

## 验收

所有清理只作用于 ExLab 有归属证明的内容；暂停、待续训、待回传与共享内容有明确保护。迁移异常、证据校验失败、符号链接、状态变化、其他容器并存均有回归覆盖。记录大历史数量下的重复扫描、命令次数和耗时对比；运行完整跨平台与原生 UI / 更新器检查。远程服务器实际迁移、未登录启动及磁盘回收需独立验收，不用模拟测试代替。
