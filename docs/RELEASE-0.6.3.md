# ExLab 0.6.3 · 后台排队迁移

- 修复迁移在进入等待阶段之前就因容器或 WSL 正在运行而被拒绝。现在可点击 **排队迁移并开启**，暂停本节点的新接单，让当前实验与回传自然结束，再自动迁移。
- 对受影响的其他容器和发行版显示等待原因，定期重新检查；条件满足后自动继续，无需手动反复重试。原位迁移仍允许不相关的容器运行。长期服务不会被擅自终止。
- 迁移在独立进程执行。关闭窗口收进托盘，重新打开可查看或取消同一项任务，不再把正常排队误报为需要恢复的故障。
- 移除等待实验的 24 小时限制；取消后恢复原配置与接单策略。实际切换前继续核对空间、节点身份和占用状态。
- 主窗口状态查询、算力操作与更新安装在迁移期间避让，防止搬盘时唤醒 WSL 或启动第二个后台。

不新增迁移计划任务，也不将 Windows 密码写入磁盘。关闭窗口后继续运行；注销、重启或进程异常退出后，需要重新授权恢复。移动正在被使用的虚拟磁盘仍需等待空闲，排队不会强行终止实验。

验证覆盖真实 Docker 容器自然结束后继续、等待取消、长任务等待、无关容器保护、单一执行者、实际窗口关闭与重开、更新和迁移回归。远程服务器未被代为操作。
