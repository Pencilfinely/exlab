# ExLab 0.5.10

Windows Center、Windows Worker 和 Ubuntu Worker 的手动及自动更新统一采用管理进程交接：Docker 实验继续运行，无需清空待执行实验、未确认报告或文件回传队列。新版继续使用原节点身份、任务数据库、容器标签、GPU 策略和 Docker 地址；重启后检查原容器，接续调度、报告和断点传输。

Worker 在完整管理循环之间确认交接，不停止或重建实验容器。正在准备环境或写入项目配置时，只等待当前本机操作完成；无法接回的本机 CPU 演示或无法识别的任务状态仍需先处理。Docker 未运行或暂时不可访问不再阻止管理软件安装。Windows 的 WSL 会话在短暂更新交接期间保留，不执行 Docker/WSL 资源释放。

升级已发布的 0.4.x / 0.5.9 Worker 时，新入口使用经过进程身份核验的普通停止操作，仅退出旧代理，保留 Docker 实验与数据。旧版应用内更新入口仍采用旧规则，需要先使用本版包完成首次交接；Ubuntu 离线机器可沿用手动本地安装流程。安装失败保留并恢复原后台配置、systemd 单元与运行选择。

Windows 与 Ubuntu 三个发行包包含相同的共享后端。Monitor 的 APK 更新不依赖实验状态，其版本保持 0.5.2。自动更新选项仍默认关闭。

完整命令与旧版迁移说明见 [运维说明](OPERATIONS.zh-CN.md)。
