# ExLab 0.5.18 — 主控历史记录较多时仍能打开和更新

修复历史实验的内嵌启动命令反复进入状态轮询，导致主控页面卡顿、客户端判定无法连接、更新一直等待的问题。真实 815 条实验记录中，状态响应从约 94 MB 缩减至约 2.6 MB；实验定义、执行状态和结果均保留。

- 工作空间状态列表省略任务启动命令。实验详情、节点接收任务及检查点恢复仍使用完整配置；移动端、规则巡检及 AI 拓扑查询使用摘要。
- 新增带管理员认证的本机健康接口，仅返回版本、节点数、实验数和运行实例身份，不读取完整任务配置。同步 Center 查询本机健康，不转发给上游。
- 启动、打开工作空间和更新检查使用轻量健康接口。旧版返回 404 时才回退状态接口，并给予旧主控足够的响应时间完成首次升级。认证失败、连接失败或无效健康响应仍阻止不安全交接。
- 页面状态刷新尚未结束时复用当前请求，避免慢连接不断叠加轮询。Windows 客户端中止连接时不再重复记录连接中断的异常堆栈。

提供 Windows Center/Worker 安装器与 ZIP、Ubuntu Worker ZIP、Android Monitor 0.5.18 APK（versionCode 9，沿用原签名），附 SHA-256 清单与构建信息。旧仓库提供相同字节的 Windows 安装器。HarmonyOS 工程同步版本，未提供原生 HAP。
