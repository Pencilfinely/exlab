# ExLab 0.5.5

实验记录、实验矩阵及矩阵结果增加高度上限与分页。可以选择每页数量、前后翻页、直接跳转首页或末页，以及输入页码；自动刷新保留当前页、筛选条件和列表滚动位置。无需为了操作列表下方的按钮滚过全部历史实验。

实验和矩阵列表直接显示完整创建日期时间。实验列表和矩阵结果还显示完成或最近停止时间；优先使用算力端回传的结束时间，没有此记录的旧实验显示主控确认时间并标注来源。运行中的实验不显示完成时间。

新增共用的彩色标签，支持创建、搜索、修改名称和颜色、删除，以及为每条实验或矩阵选择多个标签。列表可按标签、未打标签、关键词和实验状态筛选。新建实验与矩阵也可选择标签；矩阵启动时将当前标签带到新批次实验，后续修改矩阵标签不重写历史实验标签。标签保存在主控数据库中，随多主控快照同步；标签不参与算力调度，也不修改已提交任务的参数和资源。

算力管理中的「任务模板」改为独立的表单弹窗。左侧搜索并选择模板，右侧调整本次名称、参数、资源预算、标签和算力分配。可以预览分配、提交一次实验，或转为矩阵继续配置批量实验。切换模板保留各自的有效输入，自动刷新不重置编辑内容；提交结果未确认时原样重试会复用提交标识，避免重复创建实验。默认选择模板来源节点，离线或暂停时明确提示等待原因。

升级时自动为已有主控数据库增加标签表，保留实验、矩阵、执行状态、原始参数与时间记录。使用多个 Center 时，各主控应升级到同一版本后继续同步。更新完成后重新打开或刷新实验台页面即可使用新界面。

本次提供 Center / Worker 的 Windows 安装器和便携包、Ubuntu Worker 包，以及旧仓库兼容更新入口。Monitor APK 保持 0.5.2，此次无需更新手机端。

验证覆盖标签持久化与旧数据库迁移、权限校验、批次标签继承、原任务与时间记录保持、失败回滚、提交重试、分页筛选和模板草稿保留。浏览器实测使用 67 条实验与 23 个矩阵，完成标签创建、改名、改色、关联、筛选、模板提交及转矩阵保存。
