# ExLab 0.5.26 — 修复 Windows Worker 启用算力误判

Windows Worker 后台实际使用 `online` / `offline` 回报连接状态，客户端原来的启动检查只识别 `running`，导致已连接的节点仍被显示为“恢复接单失败：已连接管理端”，短暂断线也会立即结束启用过程。

- 启用检查接受后台实际的 `online` 状态；后台存活且确认在线后才报告成功。`offline` 状态继续等待重连，后台已退出或确实失败仍显示错误。
- 手动启用先检查原后台，直接复用仍在运行的原节点，避免重复安装。成功后清除旧的停用/失败提示，并记录本次请求、成功或失败，便于定位。
- 回归测试由 Python 后台生成真实状态，再交给 Windows 原生客户端检查，覆盖准备、离线重连、上线、旧版状态及无活进程的历史在线记录。

保留 0.5.25 的 Center 端口独占、工作空间校验及配置恢复修复。沿用已有节点凭证、实验和 Docker 数据，不需要重新配对。本版未增加 Worker 未登录自启功能。
