# ExLab 0.6.14

- Worker 分片同步已安装模板目录，超过旧版 100 条或心跳体积限制时仍能连接并分配实验。因旧模板上限失败的部署会在升级后重试。
- Center 默认每五分钟检查一次。成功完成且至少 14 天未使用的项目会在核验项目包后归档，并回收节点模板和部署副本。保存的矩阵和可续训任务继续保留。可在部署清理进度里恢复项目。
- Worker 可在实验运行期间回收低空间下的废弃下载和重复项目包。常规空闲维护继续清理已核验的权重副本、容器和缓存。Center 同时清理超过七天的废弃上传。

Center 与 Worker 更新到本版后即可使用分片目录。Windows 虚拟磁盘文件的物理压缩需要停用 Worker。
