# ExLab 0.5.3

修复 Worker 停用或退出时被已不存在的旧实验容器阻塞的问题。部分 Docker CLI 版本返回小写的 `error: no such object: expman-…`，旧版只识别大写开头的错误，导致历史实验已完成仍显示“退出尚未完成”。现在兼容不同大小写与 `object` / `container` 格式，并核对错误中的容器名称。

确认容器不存在前仍需成功连接 Docker；连接失败、权限错误、容器归属不符，以及最终扫描发现仍在运行的受管容器，都会继续阻止退出。历史实验结果、检查点、配置和数据保留；原本记录为运行中的实验若容器确实已丢失，会记为中断，等待手动恢复。

本次发布 Center / Worker 桌面安装器与便携包，以及 Ubuntu Worker 包，可通过软件内更新器安装。旧仓库的兼容更新入口同步提供相同安装器。

Monitor APK 最新版本仍为 0.5.2，可在 [0.5.2 发布页](https://github.com/Pencilfinely/exlab/releases/tag/v0.5.2) 下载；手机应用内更新检查会自动跳过仅包含桌面端修复的版本。
