# ExLab 0.5.4

修复 Center 更新时被旧命令行后台阻塞的问题。此前 `Start-Controller.cmd` 和命令行启动使用独立的后台入口，客户端无法让它正常停用或为更新停止；旧进程留下的记录还会让客户端误判后台可由它管理。

现在命令行与桌面客户端使用同一套主控运行流程，都支持“停用并释放资源”和应用内更新。后台的进程、版本与本次运行身份会共同核对，过期记录不会被当作当前后台。命令行仍支持打开浏览器、指定端口和 Ctrl+C 正常退出。

若连接的是升级前已经运行的旧命令行后台，更新提示会明确要求在原启动终端按 Ctrl+C 退出；受客户端管理的旧后台则提示点击实际存在的“停用并释放资源”。恢复时继续使用原数据目录，保留实验记录与连接凭证。远端实验可继续运行；本机正在处理的导入、请求与传输仍会阻止自动更新。

更新窗口保留发布说明的换行和段落，避免整段文字挤在一起。

Center / Worker 桌面安装器与便携包、Ubuntu Worker 包及旧仓库兼容更新入口同步发布。Monitor APK 最新版本仍为 0.5.2，此次无需更新手机端。
