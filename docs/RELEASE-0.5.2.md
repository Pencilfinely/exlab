# ExLab 0.5.2

移动端入口改为设备卡片，配对页统一样式。主控可复制包含地址与移动凭证的配对链接，在新版 Monitor 中粘贴一次即可接入。手机默认记住配对，下次打开直接连接上次的实验台；暂时离线时自动重试，恢复后继续同步。凭证被撤销后会退出并清除本机保存的凭证。

设备凭证新增“长期有效，直到撤销”，新设备默认采用此选项。原有定期凭证保留原来的期限；在主控的移动端设备列表点击“设为长期”可继续使用原凭证，无需重新签发。权限仍由主控逐次验证。

Android APK 顶部新增“更新”：检查正式发布中的 Monitor 版本，下载并核对 SHA-256、包名、版本与签名，再调用系统安装器覆盖更新，保留配对数据。主控暂时离线时也可检查 APK 更新。兼容环境缺少安装器或安装权限设置时，提供导出已校验 APK 的入口，供原兼容环境覆盖安装。

目前使用旧 APK 的手机需要先覆盖安装一次 `ExLabMonitor-0.5.2-android-debug.apk`，之后可在应用内检查更新。主控也需升级至 0.5.2，才能使用长期配对、配对链接和新的入口。Android APK 继续使用原包名与原调试签名；不要卸载旧应用，以便保留其配对存储。

使用新增的 `assets/monitor.svg` 生成 Monitor 图标，包括多尺寸 ICO / PNG、Android 各密度启动图标、自适应、圆形和主题单色图标，以及手机网页和 HarmonyOS 母版。原始设计文件保留。

桌面程序、窗口、快捷方式和文件描述统一为 **ExLab Center / ExLab Worker**。安装器会迁移属于本应用的“实验台”“实验算力”及旧开始菜单快捷方式，并沿用原配置与数据目录。

网页界面随主控更新，移动端连接页提供检查并加载最新界面的入口。原生 HarmonyOS 工程的图标同步更新，本次交付为 Android APK；鸿蒙 6 兼容环境中的安装器调用与真机体验需在实际手机上确认。
