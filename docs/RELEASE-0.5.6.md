# ExLab 0.5.6

Worker 窗口与托盘统一为 **停用并释放资源**，合并原来的“释放 WSL 内存”入口。一次操作先请求本机实验保存并停止，确认 Worker 已停止后再检查并释放空闲的 Docker 与 WSL；Center 保持运行，镜像、数据、实验记录与连接身份保留。

已停用后再次点击同一按钮会重试释放。已关闭的 Ubuntu 不会被检查操作重新启动，Worker 停用后也不会继续通过状态轮询唤醒 WSL。

Ubuntu 中存在其他会话或程序时，列出进程并询问是否关闭。选择保留时明确显示“WSL 内存尚未释放”，可以稍后重试。其他运行中的容器或算力代理会阻止关闭其运行环境；其他 WSL 系统仍会保留。释放后会复查 Ubuntu 状态，其他程序立即重新启动它时不会报告内存已完全释放。

自动释放选项改为 **退出客户端时自动释放空闲的 Docker 与 WSL**，仅影响客户端退出，保留原选项设置。主动点击“停用并释放资源”始终尝试释放，并在需要关闭其他会话时确认。退出检查、资源检查或释放失败会保留可重试的状态。

验证覆盖窗口和托盘单一入口、实验保存完成前禁止释放、取消停用、已停用后重试、已关闭 Ubuntu 不被唤醒、失败与缺失状态、其他会话确认、其他容器与 WSL 系统保护，以及释放后的关闭复查。Monitor APK 保持 0.5.2。
