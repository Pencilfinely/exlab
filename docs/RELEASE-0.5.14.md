# ExLab 0.5.14 — rules, AI review and verified resource release

## 高频规则巡检，低频 AI 研判

- 默认每 10 秒执行规则巡检，不消耗模型额度；AI 最短研判间隔为 15 分钟，活跃任务每小时复查。默认每小时最多 4 轮、每轮最多 6 次模型交互，界面统一展示轮数预算与调用上限。
- AI 可预览并维护自己编写的受限 JSON 规则，支持白名单条件、持续时间、冷却和有限控制效果。不执行任意脚本；规则动作仍受操作授权、人工限制、版本检查和行动限额约束。
- Center 与 Monitor 共用紧凑的巡检界面，概况、研判记录、规则库分开；记录分页、报告按需弹窗查看，检查详情默认折叠。

## 三档节点操作与执行核验

| 操作 | 现有实验 | 任务与资源 |
|---|---|---|
| 暂停接单 | 继续运行 | 保留现有资源占用 |
| 停止实验并暂停接单 | 请求保存并确认停止 | 保留本机任务归属及容器环境，等待显式续训 |
| 停止实验、暂停接单并释放训练资源 | 请求保存并确认停止 | 归还可交接任务，清理已停止的本节点实验容器，核验训练进程退出 |

策略 ACK 只证明接收。独立的 `compute_control` 回执绑定实际生效的策略，分别报告正在停止、正在释放、已停止、已释放与执行未完成。旧回执、失联、Docker 检查失败、准备操作未退出或残留运行容器，均不能显示为已释放；持续的核验失败由规则巡检发现。自动托管与外部模型使用同一套状态确认。

Windows Worker、Linux CLI、Center 和 Monitor 均支持这三档操作。需同时升级 Center 与 Worker，旧 Worker 未提供停止/资源释放核验能力。训练资源释放保留轻量控制代理和共享 Docker/WSL；完全退出虚拟机并释放 WSL 内存使用 Windows Worker 的「停用并释放 Docker / WSL」。实验状态、续训检查点与轻量最终结果继续分别传输。
