# ExLab 0.5.8

本版合并轻量结果回传与桌面启动、更新队列改进。提供 Windows Center / Worker 安装器和完整 ZIP、Ubuntu Worker ZIP、SHA-256 校验清单。Monitor APK 保持 0.5.2。

## 每个实验及时回传一个结果

新任务默认每个实验只回传一个结果 JSON；批内某组结束即可登记并可见，无需等待整个批次。结果通过独立优先通道回传；检查点、完整日志、训练历史和证据包在节点保存独立快照，只在明确请求证据 ID 后上传。

稳定的结果信封区分验证与测试指标，保留原始精度、完整被选 checkpoint 哈希、配置与源码来源、实际运行环境、分项耗时和证据索引。相同身份与相同内容的重试复用原回执，内容冲突单独记录。超过建议的 64 KiB 会提示并保留字段，不重跑训练。

页面与认证 API 区分执行完成、结果送达、证据送达和独立验收；远端通过不能自动冒充本机独立验收通过。增加待传字节、已确认偏移、错误与重试、上传器心跳及实际版本信息。

已有任务保持旧回传规则。指定项目/job 的迁移工具先 dry-run、再应用审阅清单，在已确认分块边界让出大文件，保留源、缓存、哈希、任务身份和偏移。缺少实验/attempt 绑定、旧节点不支持或缓存缺失时明确拒绝迁移，不伪造完成。

[结果协议、模板接入、外部收集器兼容与迁移/回滚](LIGHTWEIGHT-RESULTS.zh-CN.md)。升级应用本身不会自动迁移现有队列、重新提交训练，或解除已有科研隔离。

## 可选启动与自动更新

Worker 新增“启动客户端后自动启用算力”，与 Windows 登录启动分别设置。Center / Worker 新增“自动检查、下载并排队安装更新”。两个选项默认关闭，保留现有节点身份与资源配置。

更新可点一次排队下载并安装；自动等待客户端操作、实验和回传满足安全条件，失败退避重试，关闭更新窗口或重启客户端后继续。排队不会停止运行中的实验。启用自动更新后，在启动时及每小时检查同角色、同渠道的新版本。

安装完成并启动新版后，等待安装进程退出，再按路径、大小与 SHA-256 删除本次标准命名安装包。失败保留安装包，文件被占用时稍后重试清理。原数据目录、Ubuntu、配对身份、资源配置及登录启动选项保留。

[桌面选项、排队与清理操作](OPERATIONS.zh-CN.md)。旧后台不支持安全停止时，按队列提示人工退出旧后台；不要重复提交科研任务来更新应用。

## 升级兼容

需分别升级 Center 与 Worker 才能使用完整新协议。新的轻量任务只分配给声明结果通道能力的 Worker，旧任务继续执行并回传。旧实验台更新器在原仓库仍可下载相同字节的兼容安装包；安装后使用 ExLab 更新入口。

本版未改动算法、训练参数、选模规则、测试次数、实验预算或训练并发。验证使用模拟实验和测试文件，包含批内及时送达、受控大文件阻塞、断线续传、重复与冲突、按需 checkpoint、迁移保护、隔离保持，以及桌面开关持久化、队列恢复、取消和安装清理。
