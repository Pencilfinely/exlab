# ExLab 0.6.6

## Center 直接控制运行资源

算力卡片新增“停用并释放 Docker / WSL”和“启用资源并接单”，与“暂停 / 停止”入口并列。直接停用持续到手动恢复，也可以在暂停窗口选择恢复时间。Windows 控制代理在算力环境关闭后保持在线，Center 正确显示控制在线状态。无人值守后台回传资源启动进度和启动失败原因。

## 减少无人登录迁移空间

迁移默认保留 Ubuntu 数据位置，搬盘改为主动选择。空间检测使用 Docker 去重后的镜像存储统计，避免多个环境共享的 CUDA / PyTorch 层重复累计。预算另计单镜像加载峰值、仓库和安装余量。

仅传输当前配置与历史任务仍引用的缓存镜像；历史已淘汰的缓存保持按需获取，原始实验数据、记录和仓库保留。迁移在当前实验结束后自动执行，完成 CUDA 验证后登记开机任务。设置时在本机输入一次 Windows 账户密码，以后开机无需登录。

## 升级方式

已安装的 Center 和 Windows Worker 请使用“检查更新 → 下载并排队安装”。更新流程先交接管理进程，运行中的 Docker 实验继续。正式更新同时提供 Windows 安装包、完整 ZIP、Ubuntu Worker 包和 SHA-256 校验文件。

## 验证

迁移空间、历史镜像保留、节点控制和退出流程回归测试通过；Windows 原生安装及更新测试通过。双 2080 Ti 节点完整迁移预检通过，临时空间预算约 32 GiB。无人登录重启与 GPU 任务验收在节点完成迁移后执行。
