# ExLab 0.5.1

修复 Center 更新被远端实验状态永久阻塞的问题。例如断连的 A6000 上仍有“运行中”和“就绪”记录时，旧版会提示“2 个实验或操作尚未完成”，导致主控无法安装更新。

Center 现在只等待本机正在执行的请求、导入和文件写入完成，然后禁止新写入并正常停止管理服务。远端实验、待确认命令、项目分发与文件回传记录保存在原数据库中，重启后继续同步。节点离线不会使 Center 升级一直等待；也不会将实验改为完成、失败或取消。

Worker 继续检查本机训练容器、准备工作、实验保存和回传状态。主控与算力端的更新条件分别按实际资源所有者判断。

0.4.5 更新器和旧仓库升级入口继续兼容。已运行的旧 Center 若出现上述拦截，需先在客户端停止主控并退出，再运行安装包；远端训练会继续，原数据目录继续沿用。升级后的 Center 支持在这些远端状态存在时使用软件内更新。

本次验证包括：带离线运行记录的真实 HTTP 协作停止、数据库与节点身份保持、半传结果的断点续传、实际本机请求与导入的阻塞检查，以及旧更新器识别和安装包自检。

ExLab 0.5.0 的功能与多主控使用方式见 [0.5.0 说明](RELEASE-0.5.0.md)。Android Monitor 仍使用 0.5.0 测试包，HarmonyOS HAP 仍待平台构建与真机验收。
