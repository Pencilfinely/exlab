# ExLab 0.6.2 · Worker 数据盘选择

- 一键迁移增加 **Worker 数据位置** 和 **检测空间**。原先选择的目录仅保存配置备份，Ubuntu 与独立引擎仍占原盘；现在可先把 Ubuntu 移到 E 等数据盘，再迁移引擎。
- 跨盘检查包含现有 VHDX 文件及新环境所需空间，显示缺口；等待实验结束和实际移动前再次核对。默认优先使用非系统盘，不在 C 盘生成整套导出文件。
- 使用 WSL 官方移动命令，保留 Ubuntu 名称、Linux 默认用户和节点身份。迁移日志记录磁盘身份，失败或中断时校验位置；成功改盘后恢复配置仍保留新位置。
- 处理 WSL 停止发行版后仍占用磁盘的情况：仅在没有其他运行任务时，短暂重启空闲 Docker / WSL。遇到其他容器或发行版，会提前列出具体名称。原位迁移继续允许不相关的 Desktop 容器运行。
- 修正 WSL 帮助命令返回码兼容性；空间检测在后台执行，管理员授权保留所选数据目录。

在 Worker 的开机启动向导选择空目录（如 `E:\ExLabWorker\Ubuntu-Data`），先点 **检测空间**，再迁移。改盘要求 WSL 2.7.14+ 与支持 `desktop start/stop` 的 Docker Desktop。

这不会迁走 Docker Desktop 原共享磁盘或全局 WSL swap。远程机器仍须在迁移后完成 GPU 和未登录重启验收。

验证包括真实临时 WSL 磁盘 C→E 移动、启动后内容与默认账户核对、原文件释放，以及空间不足、磁盘身份不符、恢复、Docker 暂停失败和其他工作保护测试。实际本机 Worker 与运行中的实验未参与测试。
